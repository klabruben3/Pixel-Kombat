# Pixel Kombat: Genesis (PKG)

![Pixel Kombat Logo](path-to-your-logo.png) <!-- optional -->

## Overview

**Pixel Kombat: Genesis** is a retro-inspired arcade maze game that pays homage to the classic Pac-Man, reimagined with modern pixel graphics and unique gameplay mechanics. Navigate intricate mazes, collect pellets, avoid enemies, and strategically unleash a powerful laser to survive tight situations.

---

## Gameplay

- **Maze Exploration:** Move through colorful, maze-like levels collecting pellets.  
- **Enemy Avoidance:** Avoid chasing enemies that patrol the maze.  
- **Rechargable Laser:** As you collect points, your laser gradually charges. Once fully charged (5000 points), you can release it to clear enemies temporarily. Using the laser does **not award additional points**, maintaining the core “eat to score” Pac-Man philosophy.  
- **Classic Inspiration, Modern Twist:** While the gameplay follows the familiar Pac-Man mechanics, Pixel Kombat introduces new visuals, levels, and a tactical beam attack to enhance strategy.

---

## Features

- Retro-inspired pixel graphics  
- Classic arcade maze gameplay  
- Point-based progression system  
- Rechargable laser as a tactical escape tool  
- Challenging enemy AI  
- Windows executable (`pkg.exe`)  

---

## Installation & Running

1. Download the executable (`pkg.exe`) from the release page.  
2. Run `pkg.exe` on a Windows system.  
3. Navigate the maze, collect pellets, avoid enemies, and enjoy!  

> **Note:** This game is currently compatible with Windows only.
